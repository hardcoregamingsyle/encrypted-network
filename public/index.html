hrdlock

Lock a file in your browser, store it, open it later with the password.

Locking needs a secure page. Open this site from http://127.0.0.1:3000 or put it behind https.

Fingerprint of your file

Keep this too. It lets you check later that a file is exactly the one you locked.

  1. The page makes a random password.
  2. Your file is locked right here in the browser.
  3. Only the locked copy goes to the server.

    Check a file

    Pick a file you downloaded and paste the fingerprint you saved when you locked it. If they match, the file is exactly the one you uploaded, not one byte different.

    The server never gets your password or your real file. Anyone who can open this site can see the list of file names and download the locked copies, but they cannot open them without the password.
